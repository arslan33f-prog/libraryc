IMS REPORTS | STOCK STATUS

Import Stock from PDF

PDF se sirf yeh columns parhe jate hain: Item Code, Item Description, Unit, Balance (Qty banta hai) aur Avg Rate (Rate banta hai). Baaki columns chhor diye jate hain. PDF chunein ya yahan drag karein. Items aur un ki category PDF se khud pehchani jati hain (PDF ke category column ya heading se, warna item ke naam se). Preview mein check kar ke "Add to Stock" dabayein. Neeche ke box sirf tab kaam aate hain jab category na mile.
PDF mein Item Code, Description, Unit, Qty, Rate jaise columns hon to behtar parhi jati hai. Internet zaroori hai, aur scanned (tasveer wali) PDF nahi parhi jati.

PDF file yahan drag karein ya chunein

Smart Import (Claude)

Koi bhi picture, PDF, Excel ya Word file chunein. Claude use parhega, phir aap se poochega ke is ka kya karna hai: Purchase Order banana, Stock mein add karna, ya file ko jaisi hai waisi save karna. Purchase Order sirf draft ban kar khulta hai aur Stock preview mein check kar ke hi add hota hai, is liye aap ke dekhe baghair kuch save nahi hota.

API key sirf is browser mein save hoti hai (console.anthropic.com se milti hai). Har file parhne ka thora kharcha aap ke API account se hota hai, aur Claude.ai ki subscription se alag hai. Jo bhi is computer par yeh page kholay wo key dekh sakta hai, is liye key kisi ko na dein. Internet zaroori hai.

Picture, PDF, Excel ya Word file yahan drag karein ya chunein

Saved Files

Yahan woh files hain jo aap ne "Save file as it is" se save ki hain. Yeh sirf is browser mein rehti hain aur Backup tab ki JSON file mein shamil nahi hotin, is liye zaroori files kabhi kabhi Download kar lein.

File (picture, PDF, Excel, Word) bhi attach kar sakte hain. API key "Smart Import" tab mein save hoti hai.
